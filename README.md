### 3. WHO Global Health Analytics Dashboard

**Microsoft Fabric | Power BI | PySpark | API | Data Engineering | Data Analytics**

#### 📋 Project Overview

An end-to-end global health analytics project analysing **life expectancy and healthcare infrastructure across countries and regions from 2000 to 2021**.

The project was developed using **Microsoft Fabric and Power BI**, covering the complete journey from API data ingestion through transformation, modelling and interactive visualisation.

#### 🎯 Problem Statement

Global health indicators vary significantly between countries and regions. The objective of this project was to analyse long-term health trends and disparities by combining health indicators with healthcare infrastructure information.

The analysis focused primarily on:

* Life expectancy
* Hospital bed availability
* Country-level trends
* Regional comparisons
* Changes over time

#### 🏗️ End-to-End Data Architecture

```text
API Source
    ↓
Bronze Layer
Raw Data Ingestion
    ↓
Silver Layer
Data Cleaning & Transformation
    ↓
Gold Layer
Validated & Modelled Data
    ↓
Power BI Semantic Model
    ↓
Interactive Dashboard
```

#### 🔧 Tools & Technologies

* Microsoft Fabric
* Microsoft Power BI
* PySpark
* Python
* REST API
* Lakehouse
* Data Transformation
* Star Schema
* Semantic Modelling
* Data Visualisation

#### 🔍 What I Did

1. Connected to a real-world health data API.
2. Ingested raw data into the **Bronze layer** using PySpark notebooks.
3. Cleaned and transformed the data in the **Silver layer**.
4. Created validated and analytics-ready datasets in the **Gold layer**.
5. Designed a **star-schema-based data model**.
6. Built the Power BI semantic model.
7. Developed interactive Power BI visualisations for analysing global health indicators.
8. Compared countries and regions across different periods.
9. Used the transformed data to identify differences in life expectancy and healthcare infrastructure.

#### 📊 Key Insight

Japan recorded the highest average life expectancy in the analysed dataset at approximately **83.16 years**, while Lesotho recorded the lowest at approximately **48.09 years**.

This highlighted the significant differences in health outcomes across countries and provided a starting point for investigating broader healthcare and socioeconomic factors.

### 4. AdventureWorks Sales Dashboard

**Power BI | SQL Server | Excel | Web Data | Power Query | DAX**

#### 📋 Project Overview

A Power BI sales dashboard developed using the **AdventureWorks Sales dataset**, with a focus on analysing sales performance for **June 2008**.

The project demonstrates how data from multiple sources can be combined, transformed and modelled in Power BI to create an interactive sales reporting solution.

#### 🎯 Problem Statement

The objective was to develop a sales dashboard that combined information from multiple sources and presented sales performance through interactive visualisations.

The project involved integrating data from:

* SQL Server
* Excel
* Web data

#### 🔧 Tools & Technologies

* Microsoft Power BI
* SQL Server
* SQL
* Power Query
* Excel
* Web Data
* DAX
* Data Modelling
* Data Visualisation
* Power BI Service

#### 🔍 What I Did

### 1. SQL Server Data

Connected Power BI to the **AdventureWorksLT SQL Server database** and wrote a SQL query to retrieve the required sales data.

The data was then loaded into Power Query for further preparation.

### 2. Data Preparation

Performed data preparation and transformation operations including:

* Renaming columns
* Creating calculated columns
* Join queries to combine the data
* Creating views
* Cleaning and structuring the data

The main queries were organised as:

* **Customers**
* **Sales**

### 3. Data Modelling

Created relationships between the **Customers** and **Sales** tables in Power BI's Model view to enable analysis of sales performance by customer attributes.

### 4. Web Data Integration

Retrieved US state codes from a web source and imported the data into Power Query.

The data was then:

* Cleaned
* Unwanted rows removed
* Unnecessary columns removed
* Structured for integration with the sales data

### 5. Excel Data Integration

Imported US state sales information from Excel.

Used **Power Query Merge Queries** to combine the Excel data with the sales data from SQL.

### 6. Dashboard Development

Created an interactive Power BI dashboard using a range of visualisations, including:

* Clustered bar charts
* Clustered column charts
* Donut charts
* Gauge charts
* Funnel charts
* Map visualisations

### 7. Publishing

Published the completed report to **Power BI Service**.

#### 📊 Analysis Focus

The dashboard was designed to provide a view of:

* Sales performance
* Customer information
* Geographic sales distribution
* State-level performance
* Sales trends and key performance indicators

#### 💡 What I Learned

This project provided practical experience in **combining different data sources** and transforming them into a single analytical model.

It also strengthened my understanding of:

* SQL-based data extraction
* Power Query transformations
* Data integration
* Relationships between tables
* Power BI data modelling
* Interactive dashboard design
* Power BI Service publishing

#### Who Can Use the Dashboard?

* Sales Managers
* Sales Operations teams
* Regional Managers
* Commercial Analysts
* Business Managers
* Senior Management

#### How they could use it:
To monitor sales performance, compare geographic performance, understand customer activity and identify areas requiring further investigation.
